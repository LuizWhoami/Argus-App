# bounty-agent (Fase 1)

Agente autonomo de Bug Bounty — MVP com CLI, scope engine,
adapters (subfinder, dnsx, httpx), SQLite e logging.

## Uso

    pip install -r requirements.txt
    python -m bounty_agent scan example.com
    python -m bounty_agent scan example.com --dry-run

## Aviso

Uso exclusivo em programas de Bug Bounty e ativos autorizados.
Respeite escopo, rate limits e regras do programa.
